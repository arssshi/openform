# Openform roadmap

## Release 1 — the foundation (superseded by Edition 02)

- [x] 48 original, distinct identity systems.
- [x] 576 primary downloadable assets in the first foundation release; Edition 02 now provides 1,440 primary files.
- [x] Eight visual approaches and eight curated collections.
- [x] Original marks, composed previews, named palettes, and type pairings.
- [x] Self-hosted, openly licensed fonts with original notices.
- [x] Portable, outlined SVG artwork.
- [x] Static catalog API, design tokens, CSS themes, and guidelines.
- [x] Individual downloads, complete kit ZIPs, and complete-library ZIP.
- [x] Search, composable filters, sorting, saved identities, and deep links.
- [x] Live type playground and website integration examples.
- [x] Browser tests and automated catalogue/asset validation.
- [x] Contribution standards and repository workflow.

## Edition 02 — complete visual worlds and installable themes

- [x] Reauthored master symbols and individual art direction for all 48 identities.
- [x] Original signature illustrations and composed identity boards.
- [x] 1,440 primary files: 30 per identity.
- [x] Stationery, packaging studies, business cards, web directions, and vertical campaigns.

- [ ] Contributor attribution, system revisions, and changelogs.
- [ ] A reviewed submission workflow and public request board.

- [ ] Optional npm package and framework integration examples.
- [ ] Search facets for color, font classification, and available applications.
- [ ] Stable versioned catalog API and asset checksums.

## The standard as we grow

A larger library should give people more meaningful choice. Every new identity needs a different symbol, composition, supporting pattern, typographic voice, and clear usage logic. Public adoption and rankings are earned through usefulness, design quality, and community; they are not promised by the size of the initial release.
