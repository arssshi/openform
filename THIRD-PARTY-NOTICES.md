| Project | License | Use |
| --- | --- | --- |
| React and React DOM | MIT | User interface |
| Vite and its React plugin | MIT | Development and static build |
| TypeScript | Apache-2.0 | Type checking |

| Lucide | ISC | Website UI icons, not the brand marks |

The original license and notice files for these dependencies are provided by their installed npm packages. Dependency versions are recorded in `package-lock.json`.

## Font software

The included original fonts come from the Google Fonts source repository and use the SIL Open Font License 1.1. Each file is distributed with its complete original copyright and OFL notice in `public/fonts/`, and each identity kit includes the notices for its own heading and body files.

Included families: Archivo, Bebas Neue, Bricolage Grotesque, Cormorant Garamond, DM Mono, DM Sans, Fraunces, Instrument Serif, Karla, Lora, Manrope, Outfit, Playfair Display, Prata, Rubik, Space Grotesk, Syne, Unbounded, Urbanist, and Work Sans.

Font files are unmodified. Instrument Serif additionally includes its original italic file for Openform's own website typography.
